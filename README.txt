METROLABVR WEBXR - PAQUETE LISTO PARA PUBLICAR

CONTENIDO
- index.html: aplicacion principal.
- app.js: interacciones y contenido educativo.
- styles.css: interfaz visual.
- README.txt: estas instrucciones.

PRUEBA EN COMPUTADOR
1. No abra index.html haciendo doble clic si el navegador bloquea funciones.
2. Publique la carpeta o use un servidor local.
3. En computador puede mirar arrastrando el mouse y seleccionar los puntos azules.

PUBLICACION RAPIDA EN GITHUB PAGES
1. Cree una cuenta o inicie sesion en github.com.
2. Cree un repositorio publico llamado metrolab-vr.
3. Use Add file > Upload files.
4. Suba index.html, app.js y styles.css, no solamente el archivo ZIP.
5. Confirme con Commit changes.
6. Abra Settings > Pages.
7. En Source seleccione Deploy from a branch.
8. Elija main y /(root), luego Save.
9. Espere unos minutos. La direccion sera parecida a:
   https://SU-USUARIO.github.io/metrolab-vr/

USO EN META QUEST 2
1. Conecte las gafas a internet.
2. Abra Browser en las gafas.
3. Escriba la URL HTTPS publicada.
4. Pulse Comenzar exploracion.
5. Pulse Entrar en VR.
6. Apunte a un punto azul con el controlador y presione el gatillo.

IMPORTANTE
- La pagina debe publicarse mediante HTTPS para habilitar WebXR.
- La aplicacion carga A-Frame 1.8.0 desde aframe.io, por lo que requiere internet.
- La experiencia tambien funciona como visor 3D no inmersivo en computador.
- Pruebe siempre en las gafas antes de utilizarla en una clase completa.
